# German verbes

## Verbe Regulate

### besuchen / besuchte / besucht – a frecventa

| Persoană  | Präsens (Prezent) | Präteritum (Trecut simplu) | Perfekt (Participiu trecut + haben) |
| --------- | ----------------- |----------------------------| ----------------------------------- |
| ich       | besuch**e**       | besuch**te**               | habe besucht                        |
| du        | besuch**st**      | besuch**test**             | hast besucht                        |
| er/sie/es | besuch**t**       | besuch**te**               | hat besucht                         |
| wir       | besuch**en**      | besuch**ten**              | haben besucht                       |
| ihr       | besuch**t**       | besuch**tet**              | habt besucht                        |
| sie/Sie   | besuch**en**      | besuch**ten**              | haben besucht                       |


## Verbe neregulate

| du        | kommst            | kamst                      | bist gekommen                      |
| er/sie/es | kommt             | kam                        | ist gekommen                       |
| wir       | kommen            | kamen                      | sind gekommen                      |
| ihr       | kommt             | kamt                       | seid gekommen                      |
| sie/Sie   | kommen            | kamen                      | sind gekommen                      |
