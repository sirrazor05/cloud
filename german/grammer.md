# Grammer

## Pronumele demonstrativ

Definitie:

Pronumele demonstrative sunt cuvinte care arată / indică un obiect, o persoană sau o idee.
Ele pot:
- însoți un substantiv → adjectiv pronominal demonstrativ
- înlocui un substantiv → pronume demonstrativ propriu-zis

### dieser / diese / dieses / diese

| Masculin   | Feminin   | Neutru          | Plural            |
| ---------- | --------- | --------------- | ----------------- |
| **dieser** | **diese** | **dieses**      | **diese**         |
| acesta     | aceasta   | acesta (neutru) | aceștia / acestea |


Exemple:
- **Dieser Mann** = acest bărbat 
- **Diese Frau** = această femeie 
- **Dieses Kind** = acest copil 
- **Diese Kinder** = acești copii
